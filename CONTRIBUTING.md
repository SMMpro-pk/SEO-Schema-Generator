# Contributing

Thank you for helping improve SMMpro Schema Generator.

1. Open an issue describing substantial changes before starting work.
2. Fork the repository, create a branch, and make focused changes.
3. Serve the repository root locally as described in the [README](README.md).
4. Exercise the affected functionality in a browser, including keyboard use and a narrow viewport where relevant. Check generated structured data with the validators linked in the README.
5. Submit a pull request describing the change, how you checked it, and any limitations.

Keep the application dependency-free unless a change explicitly calls for a dependency. Do not commit credentials, private data, or generated local files. Please follow the [Code of Conduct](CODE_OF_CONDUCT.md). Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md), not in a public issue.
