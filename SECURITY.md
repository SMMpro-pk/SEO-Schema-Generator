# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use [GitHub's private vulnerability reporting](https://github.com/SMMpro-pk/SEO-Schema-Generator/security/advisories/new) if it is enabled. Include the affected version or commit, reproduction steps, impact, and any suggested mitigation; omit personal information and secrets.

If private reporting is unavailable, contact the repository maintainers privately through an available channel before disclosing details. Response times and support for older versions are not guaranteed.
