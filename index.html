02 / THE BASICS

A little context goes a long way.

Structured data helps machines understand the meaning behind a page—not just the words on it.

01 / UNDERSTAND

What is schema markup?

Schema.org is a shared vocabulary for describing things on the web. JSON-LD is a format for adding that context to a page without changing its visible content.

02 / CREATE

Describe what's actually there.

Choose a type that fits your page and add accurate, visible information. Include only properties that are relevant; more markup isn't always better.

03 / PUBLISH

Test, then keep it current.

Add your JSON-LD to the appropriate page and test it with a structured data testing tool. Eligibility for rich results is not a guarantee of display.

Explore the vocabulary at Schema.org ↗ and check Google's structured data guidelines ↗.
